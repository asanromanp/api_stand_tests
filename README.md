# api_stand_tests

Proyecto pruebas automatizadas para API de Urban Grocers.

## Tecnologías
- Python
- Pytest
- Requests
- Git

## Archivos principales
- `configuration.py`: contiene la URL del servidor.
- `data.py`: contiene los datos de prueba.
- `sender_stand_request.py`: contiene las funciones para enviar solicitudes.
- `create_user_test.py`: contiene las pruebas automatizadas para crear usuarios.
